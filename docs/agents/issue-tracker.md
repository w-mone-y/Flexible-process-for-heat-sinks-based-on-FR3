# Issue tracker: GitHub

本仓库的规格和实现任务发布到
[`w-mone-y/Flexible-process-for-heat-sinks-based-on-FR3`](https://github.com/w-mone-y/Flexible-process-for-heat-sinks-based-on-FR3)
的 GitHub Issues。

## Conventions

- 使用 `gh` CLI 创建、读取、评论、标记和关闭 Issue。
- 规格以一个父 Issue 发布。
- 实现任务按依赖顺序分别创建 Issue。
- 优先使用 GitHub 原生阻塞关系；不可用时在正文中记录 `Blocked by`。
- 可直接执行的任务使用 `ready-for-agent` 标签。
- Pull Request 不作为需求或问题的入口。
