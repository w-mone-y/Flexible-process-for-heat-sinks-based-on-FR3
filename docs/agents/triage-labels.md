# Triage labels

| Canonical role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者判断范围和优先级 |
| `needs-info` | `needs-info` | 等待补充必要信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由工程代理执行 |
| `ready-for-human` | `ready-for-human` | 需要人工操作或人工判断 |
| `wontfix` | `wontfix` | 已决定不实施 |
