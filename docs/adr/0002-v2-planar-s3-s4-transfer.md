# ADR-0002: V2 S3—S4 采用水平面绕障物流

## Status

Accepted

## Context

V2 删除旧中转台后，S3A、S3B 曾使用斜直线双轨直达 S4。完整的梳齿、
翅片和压片载荷会扫过 S2B；右线托盘还会扫过 Arm3 连杆。曾尝试用垂直
抬升和高架轨道分层，但操作者明确要求所有台间物流只在水平面内运动。

仅增加逻辑互锁、利用托盘与台面之间约 1 mm 的 Z 间隙或只检查托盘底板，
都不能消除 Viewer 中的穿模。移动 S2B 会破坏 Arm3 顶视检测可达性，因此
保持现有工位位置，用完整载荷包围盒规划平面绕障路线。

## Decision

- S4 共享焊前检测台从 `(1.10, 0.00)` 移至更靠近炉前的
  `(1.40, 0.00)`；炉前缓存相应顺延，保持检测台、托盘和缓存互不重叠。
- S3A 从 S2B 北侧绕行：先沿 +X 到 `(1.40, 0.50)`，再沿 -Y 到 S4。
- S3B 从 Arm3 单元南侧绕行：经 `(0.05, -0.45)`、
  `(0.05, -1.22)`、`(1.55, -1.22)` 后沿 +Y 到 `(1.55, 0.00)`，
  再通过 0.15 m 的短轨从东侧进入 S4。
- 删除 B 线原先的北上至 `Y=0.50`、向西返回、再向南进入 S4 的回环；
  完成共享焊前检测后直接沿 +X 正向进入炉前输送线。
- 托盘载体中心全程保持 Z=0.225 m，姿态不变；不设置升降 joint、
  actuator、竖直导轨或高架等待位。
- MJCF 用连续、带斜接转角的 V1 风格双滑轨显示两条水平路线。
- Arm3 完成 B 线最后一片翅片后，先退出产品区，再收拢至经过完整载荷
  扫掠验证的关节分支；达到避让姿态前禁止释放托盘运输。
- 回归验证必须覆盖完整托盘载荷，而不是只测托盘底板：
  - 左/右托盘与 S2B 的最小俯视净空不少于 50 mm。
  - 右托盘与 Arm3 全部碰撞连杆的最小净空不少于 20 mm。
  - S3—S4 运动期间载体 Z 偏差不超过数值容差。

## Consequences

- 不恢复旧中转台，现有工位和 Arm3 基座位置保持不变。
- A 线绕行较短；B 线因 S2B、Arm3 和南侧料台形成封闭障碍，采用更长但
  可直接观察和测量的南侧外绕路线。
- B 线外绕后不再与 S2B 扫掠相交，因此 S2B 可在 B 线托盘出站期间接收
  下一件，不保留旧斜线方案的伪冲突互锁。
- 合流走廊仍为单占用；较长 B 线运输不会允许另一托盘从相反方向切入。
- 平面等待点、完整载荷净空和恒定载体 Z 成为场景、拓扑和测试共同维护
  的契约。
