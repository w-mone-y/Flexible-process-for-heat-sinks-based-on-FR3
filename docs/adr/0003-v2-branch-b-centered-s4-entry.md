# ADR-0003: V2 B 线垂直进入 S4 正中心

## Status

Accepted

## Context

ADR-0002 为避开 Arm3 单元，将 B 线南侧等待位设在
`(1.55, -1.22, 0.225)`，最后先向北移动，再水平进入 S4。这使
Viewer 中的最后一段双滑轨为斜线，与 A 线“对准 S4 正中心后
垂直进站”的视觉语义不一致。操作者明确要求左右两线在进入
S4 时对称，本次先不把 Arm3 几何净空作为最后进站段的布局限制。

## Decision

- B 线南侧等待位改为 `(1.40, -1.22, 0.225)`，与 S4 中心
  `(1.40, 0.00, 0.225)` 共用同一 X 中心线。
- `MERGE_B_WAIT → Y_MERGE_SHARED` 只产生一个目标点，托盘在水平面内
  沿 +Y 直线进入 S4，不再先北上再横移。
- 可见双滑轨最后一段分别固定为 `X=1.345` 与 `X=1.455`，
  其中心与 S4 完全重合。
- 翔片返工从 S4 返回 S3B 时严格沿正向路线的反向运行。
- 单占用合流锁、托盘唯一所有权、全程 `Z=0.225 m` 和禁止载件瞬移
  仍为强制不变量。

## Consequences

- Viewer 中 B 线不再斜着进入 S4，视觉滑轨与运行时托盘路径一致。
- ADR-0002 中关于 B 线使用 `X=1.55` 东侧安全走廊和最后横向进站
  的决策被本 ADR 替代，其余平面运输与所有权决策继续有效。
- Arm3 与此路径的最小净空不再是本次几何布局的验收条件；运行时
  仍由工位互锁和 Arm3 退让姿态防止同时占用共享区。
