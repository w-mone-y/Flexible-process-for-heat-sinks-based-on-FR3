# ADR-0005: V2 固定相机与 Arm3 末端相机协同

## Status

Superseded by [ADR-0006](0006-v2-single-arm3-camera.md)

本文件保留为历史决策记录。当前实现不再包含 S2B/S4 固定相机。

## Context

S2B 和 S4 已有固定相机，Arm3 同时具有末端相机和窄型夹爪。如果所有
检测都固定使用 Arm3，会失去第二条翅片安装支路的吞吐优势；如果只展示
四个相机画面而不协调任务、资源与采集记录，则会形成形式上的“双视角”。

## Decision

- 标准路线由 S2B/S4 固定相机执行全局主检，Arm3 优先保留给翅片安装。
- `HIGH_RELIABILITY` 固定分配到 S3B / Arm3 安装支路，并执行
  “S2B固定钎料主检 → S3B Arm3钎料近景 → 翅片安装 → S3B Arm3翅片近景
  → S4固定全局终检”；`FIRST_ARTICLE` 只对订单首件执行该路线。
- 固定结果发现缺陷时直接进入对应返工，不再要求 Arm3 前往 S2B/S4 二次确认。
- 返工后由原固定相机重新采集确认；托盘随后按自身路线继续前进。
- 固定相机离线时工件在对应固定检测台显式阻塞，等待相机恢复或人工处理；
  不生成 Arm3 接管请求。
- Arm3 检测优先，但已开始的单片翅片安装不抢占；等待只能发生在安全节点。
- 每次采集以“产品单元＋检测工序＋相机＋本次动作起点”生成唯一尝试，
  分别保存采集时间、对齐、净空和分析完成证据。
- 高可靠路线的 DAG 使用“Arm3近景复核钎料”和“Arm3近景复核翅片”真实节点，
  两者工位和区域锁均为 S3B；不再把这些节点伪装成 S2B/S4 动作。
- V2“订单规划”提供“Arm3全程复核”和“Arm3首件复核”快捷入口；对应按钮
  分别提交 `HIGH_RELIABILITY` 与 `FIRST_ARTICLE`，普通/紧急订单也可通过
  工艺路线下拉框选择同一策略。

## Consequences

- 标准订单不会因重复检测无故占用 Arm3，高可靠与首件路线则有可见、可审计的
  额外检测成本。
- 任务图、四路画面、相机协同表、故障恢复和 headless 实验共用同一请求与记录。
- S2B/S4 固定相机离线时，对应固定主检任务显式阻塞并等待恢复/人工处理，
  不允许默认通过检测，也不允许 Arm3 跨区接管。
