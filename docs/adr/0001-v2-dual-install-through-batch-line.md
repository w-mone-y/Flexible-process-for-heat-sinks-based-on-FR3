# ADR-0001: V2 双安装支路与贯通式批次炉

## Status

Accepted

## Context

V1 的单翅片安装资源长期成为多订单瓶颈。用户要求 Arm3 增加固定夹爪，
与 Arm1 在独立安装台并行安装，随后合流检测并进入前进后出的炉体。

## Decision

- 保留 V1，新增独立 V2 启动入口和 MJCF 场景。
- 焊料检测通过后，托盘动态分流到安装线 A 或安装线 B。
- Arm3 使用固定相机与窄型夹爪复合末端，不进行换刀。
- Arm3 检测优先；当前单片安装动作不可抢占。
- 两条安装支路通过单占用 Y 形合流机构进入共享焊前检测台。
- V2 使用六套托盘，组成炉内批次与上游下一批两个三件 WIP 集合。
- 炉体采用三层、前门装载、后门卸载的 CAB 批次结构。
- 工艺兼容时允许跨订单混炉；满炉、等待超时或交期风险触发炉批。
- 炉后使用带完整平面承托台的固定视觉门架进行最终分级；成品出口升降门
  位于完整检测托盘包络之外，检测完成后再沿独立输出输送段进入出口箱。
- 成品移除后的空托盘仅进行虚拟返回。

## Consequences

- V2 可以展示 Arm1 与 Arm3 的真实并行安装。
- 炉体长周期不再要求产品逆流返回。
- 需要新的托盘所有权、分流、合流、炉批和双门互锁状态。
- Arm3 的装配收益受共享检测负载约束，必须由动态调度器解释分配原因。
- 六套产品池增加模型规模，场景实现必须控制碰撞对和不可见几何开销。
