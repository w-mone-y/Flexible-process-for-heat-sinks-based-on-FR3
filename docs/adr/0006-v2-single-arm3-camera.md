# ADR-0006: V2 使用单一 Arm3 末端相机执行机器人视觉检测

## Status

Accepted

## Context

S2B、S4 独立固定相机需要额外门架、相机资源和四画面 UI，并在托盘物流与
Arm3 作业空间附近增加碰撞风险。用户决定恢复简洁场景，仅保留 Arm3 末端相机
与焊后固定相机，同时保留已经完成的高可靠近景、独立采集和分析门控能力。

## Decision

- 从 V2 MJCF 删除 S2B、S4 固定相机的 body、geom、camera、site 和 sensor。
- 从 V2 资源配置与调度绑定删除 `S2B_CAMERA`、`S4_CAMERA`。
- Arm3 末端相机在 S2B 执行钎料主检、在 S4 执行焊前终检。
- `HIGH_RELIABILITY` 与 `FIRST_ARTICLE` 路线继续在 S3B 执行钎料和翅片近景复核。
- Arm3 检测优先，但已经开始的单片翅片安装不可抢占；Arm3 离线时工件原位阻塞。
- 每次主检、近景和返工后复检均产生独立采集记录，并经过 5 秒非阻塞分析门控。
- V2 相机窗口仅显示左右双画面：Arm3 末端相机与焊后检测分级相机。
- 焊后固定相机及其成品分级逻辑不在本次删除范围。

## Consequences

- 场景与 UI 更简洁，S2B/S4 附近不再存在相机门架碰撞风险。
- 标准路线的 S2B/S4 检测会占用 Arm3，安装线 B 的可用窗口可能减少；调度器
  通过检测优先和单片不可抢占规则保持安全与确定性。
- S2B、S3B、S4 共用同一 `ARM3_CAMERA` 资源，离线影响在状态和任务图中一致呈现。
- 焊后分级仍由独立 `POST_CAMERA` 执行，不要求 Arm3 跨越炉体。
