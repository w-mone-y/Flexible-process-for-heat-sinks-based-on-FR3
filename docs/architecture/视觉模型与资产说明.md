# 视觉模型与资产说明

## 本轮结论

除仓库原有、按 Apache-2.0 保留的 FR3 官方描述与必要网格外，本场景没有再纳入
第三方设备网格。调研过的通用工业资产中，Kenney Factory Kit
和 Conveyor Kit 使用 CC0 授权，适合作为低多边形输送线素材；但当前浏览环境禁止访问
该下载源。其余炉体和点胶/钎料喷嘴候选要么不是钎焊设备，要么只有需要登录的厂家
CAD，或者没有足以支持项目再分发的清晰授权。

因此，`scenes/production/brazing_line.xml` 使用 MuJoCo 原生几何完成了本轮工业
视觉升级，避免增加不明授权的第三方二进制资产。

仓库只保留 `fr3.xml` 实际引用的 36 个视觉/碰撞网格；旧试验手爪、整链节重复网格
和未被 V1/V2 引用的抓取示例 XML 已删除。该裁剪不改变正式 FR3 的几何、惯量、关节、
执行器或许可证。

## 仓库自制铭牌

`assets/signs/` 下的 V1 站点图以及 `v2_s1_*`、`v2_s2*`、`v2_fin_*`、
`v2_s3*`、`v2_s4_*`、`furnace_sign.png` 和 `post_inspection_sign.png`
是本项目为 MuJoCo 场景自行制作的中文设备铭牌，不包含第三方图片、商标或模型内容。
V2 八张功能桌使用互不复用的 `1024 × 256` 专属纹理，由
`scripts/generate_v2_station_signs.py` 统一生成，确保站号、工序文字与台面颜色一致。
铭牌只作为视觉纹理，不参与碰撞、质量或接触计算。

## 视觉与物理分层约定

- 原有命名碰撞体、joint、actuator、site、TCP、camera 和 equality weld 保持不变。
- 新增细节统一使用 `class="visual"`，其 `contype=0`、`conaffinity=0`、`density=0`。
- 视觉模型不会参与碰撞、质量、惯量或接触求解。
- 炉门上的视觉面板是炉门 body 的子几何，因此会随原有 slide joint 连续运动。
- Arm2 喷管细节是原工具 body 的子几何，因此会随工具运动，但不会改变双喷嘴 TCP。

后续若引入第三方 OBJ/STL，应继续保留现有简化碰撞体，只把网格作为视觉几何使用，
并把原始许可证与来源一并放入资产目录。
